# Ilustrações — Gabriel e o Portal Misterioso

Coloque aqui uma imagem independente por página, sem texto embutido. Nomeie `01.webp`, `02.webp`, ... `19.webp` (também aceita PNG ou JPG). A proporção recomendada é 4:5, com personagens consistentes e área de segurança nas bordas.

Use `python empacotar_livro.py --historia books/gabriel-e-o-portal-misterioso.gbrbook --imagens art/portal-misterioso --saida dist/gabriel-portal-ilustrado.gbrbook` para gerar um livro pronto para importar no aplicativo. Para prévia parcial, acrescente `--permitir-faltas`.

Nunca incorpore o texto da página à imagem: o leitor apresenta texto em HTML, aumentando legibilidade e evitando cortes.
